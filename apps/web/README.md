# Nora Group website

Marketing site for **Nora Group** — custom carpentry and interior design.

Hebrew is the default language (`/`). Arabic, English, and Russian use prefixes: `/ar`, `/en`, `/ru`.

This is a **contact site**, not a quote funnel. CTAs are phone and WhatsApp only. The company does **not** make doors.

Content comes from **PostgreSQL** (Prisma). The Dashboard at port 3000 is the CMS.

See the repo-root [`LOCAL_SETUP.md`](../../LOCAL_SETUP.md) for install, env, and `pnpm setup:local`.

Then open:

| What | URL |
|---|---|
| Hebrew home | http://localhost:3001 |
| English | http://localhost:3001/en |
| Arabic | http://localhost:3001/ar |
| Russian | http://localhost:3001/ru |
