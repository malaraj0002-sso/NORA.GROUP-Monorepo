# מדריך קצר ל־Sanity Studio — Nora Group

## כניסה
1. היכנסו לכתובת: `https://officialnoragroup.com/studio`
2. התחברו עם המשתמש שקיבלתם מ־LazaCore
3. בצד ימין תראו את תפריט התוכן בעברית

## מה אפשר לערוך
- **הגדרות אתר** — לוגו, טלפון, וואטסאפ, אימייל, כתובת, QR, הודעות וואטסאפ, SEO
- **דף הבית / אודות / תהליך / יצירת קשר** — כל הטקסטים והתמונות
- **שירותים, פרויקטים, חומרים, המלצות, בלוג, שאלות** — הוספה / הסתרה / עריכה

## שפות
בכל שדה טקסט יש לשוניות: **עברית** (חובה), العربية, English, Русский.  
אם שפה ריקה — האתר מציג עברית.

## פרסום
לחצו **Publish** אחרי שינוי. האתר מתעדכן אוטומטית (webhook).
